# IBMZ-HEAD

## Dataset and Annex Integration

### Overview

The `data/` folder contains a **synthetic** dataset of 1,000 learners aged 16-24 (15 columns). It models who is at risk of becoming NEET (Not in Education, Employment or Training). **No real personal data is used.** Every row is generated by code.

The proportions come from the UK Department for Work and Pensions (DWP) *Young People and Work* interim report and its analytical annex data tables: <https://www.gov.uk/government/publications/young-people-and-work-interim-report>

### Files in `data/`

| File | Purpose |
|---|---|
| `neet_dataset.csv` | Main dataset for modelling |
| `neet_dataset_db2.csv` | Same data formatted for Db2 import |
| `data_dictionary.csv` | Column types, allowed values, descriptions and annex sources |
| `DATA_GUIDE.md` | NEET label logic and which columns to use as features |
| `validation_report.md` | Results of 15 automated data quality checks |
| `generate_neet_dataset.py` | Builds the dataset (fixed seed 42, so fully reproducible) |
| `validate_and_export.py` | Validates the data and writes the Db2 CSV, report and guide |

### How the annex was used

| Variable | Annex source | Status |
|---|---|---|
| NEET status, employment and education flags | Table 1 (status by ethnicity, UK, pooled 2018-2025) | From annex |
| Ethnicity categories | Table 1 | Categories from annex; population shares assumed |
| Qualification level (NEETs) | Table 24 (qualification mix of NEETs) | From annex; non-NEETs assumed |
| Benefit type (NEETs) | Table 13 (England, 18-24) | From annex; non-NEETs assumed |
| Age | Table 25 (about 7% of NEETs are 16-17) | From annex; non-NEETs uniform |
| Duration NEET (months) | Table 21 | Proxy, see limitations |
| Mental health condition | Table 57b (81% of 18-24 UC LCWRA claimants with a health condition cited) | Proxy for NEETs on UC (no work requirements) or PIP; rest assumed |
| SEND, attendance, household income, job search frequency | Not in annex | Assumptions, labelled in code and dictionary |

### NEET label

Following the ONS definition in the annex (section 29), a learner is NEET if they are **not in employment and not in education or training**:

```python
neet = int(in_employment == 0 and in_education_training == 0)
```

Some columns define or reveal the label and must not be used as model features. See `data/DATA_GUIDE.md`.

### IBM Z mapping

| Data | IBM Z structure | Why |
|---|---|---|
| Learner profile: ID, qualification, ethnicity, household income | **Db2** | Relational and queryable for analytics |
| Core learner master record (ID plus key attributes) | **VSAM (KSDS)** | Fast keyed lookup by learner ID |
| Learner to benefit claims and job-search history | **IMS** | Hierarchical parent-child data |
| Attendance updates, benefit status changes, new job-search events | **MQ** | Event-driven messages |

### Reproducing the dataset

```bash
cd data
python generate_neet_dataset.py   # writes neet_dataset.csv and data_dictionary.csv
python validate_and_export.py     # runs checks, writes Db2 CSV, report and guide
```

### Testing the saved model

Run the inference smoke tests from the repository root. They load `model/model.pkl`
and score a sample from `data/neet_dataset.csv`; no database connection is needed.

```bash
python -m unittest discover -s tests
```

### Running the Streamlit dashboard

Install the dashboard and model dependencies, then launch the app from the
repository root:

```bash
python -m pip install -r IBM-NEET-DASHBOARD/requirements.txt
python -m streamlit run IBM-NEET-DASHBOARD/app.py
```

The dashboard defaults to the synthetic `data/neet_dataset.csv` and calculates
scores with `model/model.pkl`. To read learners from the configured database,
select **Configured database** in the sidebar. Set `DB_BACKEND=sqlite` and
`DB_SQLITE_PATH` for a local SQLite database, or configure the `DB2_*`
environment variables described in `model/db_utils.py` for Db2. The selected
database must contain the configured input table and all model input columns.
Saving predictions is an explicit action and replaces the configured output
score table.

### Limitations

- The dataset is synthetic. A model trained on it recovers the relationships built into the generator and the annex proportions. It does not discover real-world causes.
- SEND, attendance, household income, job search frequency, the ethnicity population shares and all non-NEET distributions are assumptions, because the annex does not cover them.
- `duration_neet_months` is a proxy. The annex states its source measure (time out of full-time education or employment) does not measure time spent NEET.
- Only about 10% of rows are NEET, so classes are imbalanced.
- Overall NEET rates follow pooled 2018-2025 UK figures (about 12%). The latest quarterly rate is higher (13.0% in April-June 2026).

### Future data sources

- **Linked government data:** DWP and DfE linked datasets (for example RAPID and Longitudinal Education Outcomes) for real benefit, education and employment histories.
- **Local authority records:** NEET and participation tracking for 16-17 year olds.
- **College and school attendance systems:** real attendance and engagement signals to replace the assumed attendance variable.
- **NHS and mental health service data:** to replace the proxy for mental health.
- **Governance:** any real data would need a lawful basis, consent or approved access, anonymisation and compliance with UK GDPR before use on IBM Z systems.
